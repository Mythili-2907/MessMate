MESSMATE — REDESIGNED HOSTEL FOOD FEEDBACK SYSTEM

REQUIREMENTS
- Node.js installed
- Windows PowerShell or Command Prompt

RUN
1. Open this extracted folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: npm.cmd install
4. Run: node server.js
5. Open http://localhost:3000 in your browser.

ADMIN LOGIN (DEMO ONLY)
Username: admin
Password: Hostel@123

IMPORTANT DATABASE NOTE
If you have already collected feedback, copy your backed-up hostel.db into this folder (the same folder as server.js) before starting the server. If asked to replace a database, do not overwrite your only copy; keep a backup first. If no database is copied, the app creates a new one automatically.

This is a student demo project. The simple in-memory admin session and demo credentials are not suitable for production deployment.
